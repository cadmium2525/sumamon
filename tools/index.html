トークンはこの端末のブラウザにだけ保存され、送信先は api.github.com のみです。 作り方: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 対象リポジトリを絞り、Contents を Read and write に。
注意: この端末を触れる人は誰でもリポジトリに書き込めます。有効期限は短めにし、 不要になったら「トークンを消す」か GitHub 側で失効させてください。

6登録して本番へ反映

コミットすると数分後に本番へ反映されます（GitHub Pages の更新待ち）。 Service Worker のキャッシュ番号と version.json も自動で1つ上がります。

発射コマは「何フレーム目で飛び出すか」です。モーションのどのコマで手を離すかに合わせてください。 飛び道具を出す技は、体から出る攻撃判定は無くなります。
