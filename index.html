Version 1.40モンスター作成スタジオ：背景とキャラの色が近くても抜けるようにしました

※この回はゲーム側の変更はありません。モンスター作成スタジオの機能追加です。
背景とキャラの色が近い絵で、キャラの方が消えてしまう問題を直しました。実際にご提供いただいた画像で確かめたところ、キャラがほとんど消え、逆に背景が残る状態でした。
原因はキャラが画像の端で切れていることでした。これまでは画像の縁をぐるりと調べて背景の色を集めていたため、端で切れたキャラの色まで「背景の色」として登録されていました。実測すると、キャラ本体の色と「背景の色」の差はわずか5.7。抜くかどうかの目安が30なので、本体が真っ先に消えていたわけです。しきい値をいくら動かしても、本体と背景を分けられない状態でした。
そこで「背景を推定して抜く」を追加しました。縁の色をそのまま使うのではなく、「この場所の背景は何色のはずか」を画像全体にわたって割り出してから比べます。割り出す時は大きく外れた色を捨てながら段階的に精度を上げるので、端に写り込んだキャラは自動的に無視されます。
同じ画像で試すと、本体は丸ごと残り、背景は消えました。仕上げに本体から離れた小さな消し残りを自動で取り除くようにしてあるので、あとはブラシで少し整えるだけです。手に持った武器のように離れていても大きい部分は消えません。
使い分けは簡単です。ふつうの絵はこれまでどおり「四隅の色を自動で抜く」で十分です。背景とキャラの色が近い時や、キャラが画像の端で切れている時だけ、新しい方を選んでください。コマごとに選べるので、1コマだけこちらに切り替えることもできます。

Version 1.37読み込みを大幅に軽くしました（更新時が約22分の1、初回起動が約6分の1）

バージョンアップのたびに読み込みが異常に重い問題を直しました。実際に流れる通信量を測ったところ、更新1回で約72MB、初めての起動では約161MBありました。今回の修正で更新は約3MB、初回起動は約26MBになっています。原因は3つありました。

Version 1.35崖につかまったまま動けなくなる不具合を直しました

崖につかまったまま、まったく動けなくなる不具合を直しました。ご報告いただいた「ダウンしたまま崖につかまり、そこで攻撃を受けて、以降は移動もできず、殴られても微動だにしない」状態です。
原因は崖につかまっている間、のけぞりの時間が1フレームも減らなかったことです。崖では動かない扱いにしていたため、のけぞりを減らす処理まで進まず、いつまでも解けない状態になっていました。のけぞり中は操作も受け付けないため、崖を自分から離すことも、ぶら下がり時間の上限で自動的に落ちることもできず、完全に固まっていました。そこへ追撃が入るたびにのけぞりが上書きされるので、永久に抜け出せません。
直したのは3か所です。まず崖につかまっている間でも、のけぞりなどの硬直は必ず減るようにしました。次に崖つかまり中に攻撃を受けたら、手を離して落ちるようにしました（本家でも崖につかまっている最中に攻撃されれば落とされます）。そしてのけぞり中・ダウン中・ふらふら状態では崖をつかめないようにしました。操作を受け付けない状態のまま崖にぶら下がるのが、そもそもの入り口だったためです。
なお吹っ飛ばされている姿勢そのものは、これまでどおり崖をつかめます。のけぞりさえ解けていれば通常の復帰なので、復帰のしやすさは変わりません。

Version 1.32CPUを賢くしました：飛び道具を警戒し、崖から自滅せず、回避を連打しなくなります

飛び道具を撃っているだけで勝ててしまう問題を直しました。これまでCPUは飛んでくる弾をまったく見ていませんでした（弾の情報が渡っていませんでした）。これからは自分へ向かってくる弾に気づき、ガードするか、跳んで越えながら距離を詰めてくるようになります。通り過ぎた弾や、高すぎて当たらない弾には反応しません。強いCPUほど確実に対処します。
相手の追撃をかわしたあと勝手に自滅する問題を直しました。原因は2つで、復帰の目標が「画面中央」だったことと、上必殺を出すかどうかを確率で決めていたことです。中央を目指すと台の下をくぐって反対側へ抜けてしまい、抽選に外れると上必殺すら出さずに落ちていました。これからは近い方の崖を目指し、必要なら必ず上必殺を出します。台の下に潜り込んだ状態も「危険」と判断するようにしました。
レベルの差は「まずいと気づくまでの早さ」で表現しています。弱いCPUは反応が遅れるので深く落ちると戻れませんが、浅い場外でむざむざ落ちることはなくなりました。
回避の連打をしなくなりました。緊急回避は続けて出すほど弱くなるようになったため、CPUも基本はガードで受けるようになります。直前に回避したばかりの時はほぼガードを選び、シールドが保たない時だけ回避に頼ります。
そのほか、上位レベルのCPUは相手の後隙・着地隙・シールド破壊後のスキを狙って差し込み、ガード中には当たる瞬間にシールドを離してジャストガードを狙うようになりました。

Version 1.31モンスター作成スタジオ：技の発生F・持続F・後隙Fを直接指定できるようにしました

※この回はゲーム側の変更はありません。モンスター作成スタジオの機能追加です。
これまで技のフレームはコマ割りから自動で決まるだけで、「もう少し発生を早くしたい」「持続を伸ばしたい」といった調整ができませんでした。後隙だけは詳細設定から変えられましたが、発生と持続は絵の枚数に縛られたままでした。
攻撃判定の欄に「発生・持続・後隙をフレームで指定する」を追加しました。チェックを入れると発生F・持続F・後隙Fを数値で決められます。全体フレーム＝発生＋持続＋後隙になります。
コマから読み取った判定の位置と動きは、新しい持続時間へ同じ割合で割り振り直されます。武器が振られる軌道はそのままですし、多段技の段の間隔も比率を保ったまま伸び縮みします。
チェックを入れた時は今の自動計算値が初期値として入るので、そこから少しずつ動かして詰められます。外せば自動計算に戻ります。その技に既に登録されているフレームデータも参考として画面に出るようにしました。

Version 1.08スキン変更を作り直しました（狙った所を塗り分けられるように）

スキン変更が「思ったように塗れない」問題を、色の分け方から作り直して解決しました。
原因：これまでは色相（色み）だけで20°ごとにまとめていたため、明るさや鮮やかさの違いを見ていませんでした。イルミネで調べたところ、1つのまとまりが全体の47%を占め、しかも頭・胴・脚の全身に散らばっていました。マントもドレスも髪も同じ紫として扱われるので、どこをタップしても同じものが選ばれ、塗り分けようがない状態でした。
対策：色の分け方をOKLabという「数値の差＝見た目の差」が揃った色空間での分類に変えました。明るさと鮮やかさも見るので、同じ紫でもマント・ドレス・インナー・ブーツが別々に分かれます。同じ調べ方で最大のまとまりは47%→13%まで下がり、14個中9個が特定の部位に集中するようになりました。
選んでいる所が見えるようにしました。これまでは何を選んだのか画面に出ておらず、塗ってみるまで結果が分かりませんでした。これからは選択中の範囲が絵の上で黄色く光ります。
「広さ」を追加しました。同じ布の影やハイライトをどこまで一緒に塗るかを調整できます。0%ならタップした所だけ、25%（初期値）なら影も含めて自然に、100%なら全身です。離れた場所も同じ色にしたい時は「足して選ぶ」を押してからタップしてください。
色の出方も改善しました。これまでは明るさを元のまま据え置いていたため、暗い紫に明るい黄色を指定しても暗い黄土色にしかなりませんでした。これからは選んだ色を基準に置き換えるので、指定した色がそのまま出ます（陰影の起伏は保たれます）。
使いにくかった「範囲でわける」（矩形指定）は廃止しました。マントとドレスのように矩形が重なるパーツは分けられず、役に立たなかったためです。
※すでに色を設定済みのマスモンは、これまでどおりの見た目のまま表示されます。塗り直すと新しい方式になります。

Version 1.07空中の慣性を本家寄りに・被弾でジャンプが戻る問題を修正・スマッシュを強化／スタジオで技の強さを設定可能に

設定画面に「操作パッド」タブを追加し、ボタンの大きさ・濃さ・左右反転に加えて、ドラッグでボタン位置を自由に配置できるようにしました。また、ジャストガード（ガードした直後に攻撃を受けると完全に無効化して反撃できる）としゃがみを追加し、空中では慣性が働くよう本家準拠の空中制御に変更しています。崖つかまりは崖の縁にぶら下がる表示になり、掴んでいる手・残り時間ゲージが見えるようになりました。そのほか、技の発動中に攻撃を受けると技が確実に中断されるように修正し、吹っ飛び後に減速するようにして低%でも大きく流されてしまう問題を解消。画面上部中央に出ていた不要な四角も撤去しました。管理者モードでは登録済みのBGM・SEを一覧から再生できます。

Version 0.82バトルを大幅に強化・軽量化

ヒットストップ、ベクトル変更（吹っ飛び中のスティック入力で軌道を変える）、受け身、急降下、着地隙、ワンパターン相殺、ダメージに比例したガード硬直と画面揺れを追加し、より本格的な対戦の手触りになりました。また、ステータス上昇の効果が途中で頭打ちにならないよう計算式を見直し、カンストまで育成が意味を持つようにしています。合わせて、CPUが復帰技を出せずに落下するバグ、乱闘で1回の攻撃が1人にしか当たらない問題、中断・再開やマルチでモーションが失われる問題を修正し、描画処理も軽量化しました。

Version 0.81トレーニングの上昇値を適性入りで表示

トレーニングの上昇値が、選択中のマスモンの適性を反映した実際の値で表示されるようになりました。例えばちから適性Aなら重り引きでちからが+20、適性Dなら猛勉強でかしこさが+10といった具合に伸び方が変わります。修行のコース選択でも、対象ステータスの適性を確認できるようにしました。

Version 0.80適性の表示を変更

適性ランクを、太い縁取りと立体的なグラデーションを付けたアルファベット表示に変更しました。A=赤／B=紫／C=緑／D=青緑／E=青とランクごとに色分けしています。
