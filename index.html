📜 更新履歴

Version 0.78ステータス表示を刷新

マスモン管理画面で選択中のマスモンのステータスを表示するようにしました。アイコン・カラーバー・適性を並べた新しい表示で、トレーニング画面も同じ形式に統一。トレーニング内容もどの能力がどれだけ変化するかをアイコン付きで表示します。

Version 0.77バトルテストでステータスを自由に調整可能に

管理者モードのバトルテストで、自分とCPUの6種のステータスをそれぞれ入力して対戦できるようにしました。キャラやCPUレベルを変更すると、その組み合わせの既定値が自動で入ります。

Version 0.76対戦中BGMとイルミネのNBモーションを追加

対戦中に専用BGM「Pain the Universe」が流れるようになりました。また、イルミネのNB「ルミナスアロー」に専用モーションを追加し、矢が放たれるタイミングと発射モーションを一致させました。

Version 0.75バスターソードのモーション実装と5段ヒット化

専用モーション画像を反映し、3段ヒットから5段ヒットに変更しました。1〜4段目はダメージ控えめのガード不能な怯ませ判定、5段目の最終ヒットで相手を大きくふっ飛ばします。

Version 0.74バスターソードの表示と多段ヒット判定を修正

モーション画像が読み込めない場合にキャラクターが透明になってしまう問題を修正しました。また、バスターソードの途中ヒットはガード不能の怯ませ判定になり、最終ヒットのみ相手をふっ飛ばすようにしました。

Version 0.73イルミネの横B技「バスターソード」を追加

回転しながら相手を巻き込む多段ヒット技を実装しました。

Version 0.72修行でバトルと同じ技・モーションが使用可能に

修行のミニゲームが実際のバトルと同じキャラクターを使用するようになり、通常技・必殺技・スマッシュ・空中技・2段ジャンプなど全ての操作とモーションが使えるようになりました。マンディー砂漠のモノリスは頭上も塞がり、ジャンプで飛び越えられなくなりました。

Version 0.71管理者モードを拡張

修行テストでfighterを選べるようにし、実戦でモーション・技を確認できるバトルテストを追加しました。

Version 0.70マンディー砂漠の落とし穴を修正

落とし穴の真上でリスポーンし復帰不能になる問題を修正しました。

Version 0.69キャッシュ不整合を再修正

まれに古いキャッシュが再度参照されてしまう根本原因を修正しました。

Version 0.68弱Aのヒットボックス表示を修正

専用モーションがある技では黄色いデバッグ表示を出さないようにしました。

Version 0.67管理者モードのモーション確認を拡張

通常技（弱Aなど）のモーションもモーションビューアで確認できるようにしました。

Version 0.66ログイン入力欄のちらつきを修正

入力欄タップ時にキーボードが開いてすぐ閉じてしまう問題を修正しました。

Version 0.65イルミネの弱A技を強化

専用モーションのスプライトを追加しました。

Version 0.64キャッシュ不整合を修正

更新後に古い表示のまま残ってしまうことがある問題を修正しました。

Version 0.63マンディー砂漠を刷新

横スクロールの障害物走とモノリスのギミックを追加しました。

Version 0.62iPhoneのログイン入力を修正

ログイン画面で入力欄をタップしても文字入力できない場合がある問題を修正しました。

Version 0.615つの修行を実装

修行先ごとに異なるミニゲームと、結果に応じた能力成長を追加しました。

Version 0.60連戦の中断・再開

100人組手とエンドレスを途中保存し、続きから再開できるようにしました。

Version 0.59更新履歴を追加
