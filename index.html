Version 1.03

📜 更新履歴

Version 1.03起動直後に更新を促されてしまう問題を修正

起動するたびに更新のお知らせが出てしまっていた問題を直しました。原因は、更新の準備でアプリの中身を毎回すべて（60MB以上）取り直しており、準備が整う頃にはもう遊び始めていたためです。更新の準備では変更のないファイルを取り直さないようにし、画像や音声は待たずに裏で取るようにしたので、準備は数秒で終わります。あわせて、起動時に始めた更新が遊び始めたあとに届いた場合は、その場で割り込まず次回の起動時に静かに適用するようにしました。お知らせが出るのは、遊んでいる最中に新しいバージョンが公開された時だけです。

Version 1.02背景透過をキャラクター保護型に変更・スポイト追加／スタジオのプレビュー修正

背景の抜き方を変えました。これまでは画像全体から一致する色を消していたため、背景と同じ色の服や装備まで欠けたり、グラデーションの背景が抜けきらなかったりしていました。これからは画像の縁からつながっている範囲だけを抜くので、キャラクターの内側は守られます。背景の代表色も縁を一周サンプルして複数拾うため、空のようなグラデーション背景にも対応します。それでも抜け残る場合のためにスポイトを追加しました。ボタンを押してからプレビューの残った背景をタップすると、その色も背景として抜かれます。何度でも足せて、色をタップすれば取り消せます。また、登録済みのモンスターを編集する時に「体を切り分けて動かす」と「武器を振らせる」のプレビューが出なかった問題を修正しました。

Version 1.01体を切り分けて動かせるようになりました（頭・胴・脚）

立ち絵を首・腰・脚の分かれ目で切り分け、それぞれを付け根から振れるようにしました。歩行やダッシュでは左右の脚が交互に前後し、ジャンプでは脚を畳み、技では踏み込みに合わせて前後の足が開きます。頭と胴も少し遅れて動くので、生き物らしい動きになります。イルミネとデュラハンには設定済みです。スタジオでは首・腰・脚の位置をスライダーで合わせ、直立／歩行／ダッシュ／ジャンプの姿勢で見え方を確かめられます。

Version 1.00剣や斧を「振る」表現を追加（斬撃の軌跡・武器レイヤー）

技を出しても体当たりのように見えていた点を改善しました。攻撃判定の通り道に沿って斬撃の軌跡が描かれるようになり、振りの方向と速さが目で分かります。さらに、剣や斧を持つモンスターは武器だけを握りを軸に振るようになりました。スタジオのプレビューで武器を囲み、握りの位置をタップするだけで設定でき、振り角スライダーで実際の見え方を確かめられます。デュラハンには設定済みです。

Version 0.99攻撃判定の黄色表示を非表示に・管理者バトルテストのスクロール修正

専用モーションが無い技で出ていた半透明の黄色い攻撃判定表示を、通常のプレイでは出さないようにしました（動作確認用の表示だったため、自動モーションの追加で役目を終えました）。また、管理者モードのバトルテストで中身が画面に収まらず、「テスト対戦を開始」も「戻る」も押せなくなっていた問題を修正しました。

Version 0.98専用モーションが無い技・状態も動くようになりました（自動モーション）

これまで専用モーションを用意していない技や状態は棒立ちのままで、当たり判定だけが出ていました。立ち絵を上下動・傾き・伸び縮み・踏み込みで動かす「自動モーション」を追加し、歩行・ダッシュ・空中・ガード・被弾・崖つかまり、そして全ての技が動くようになります。技は「構えて引く → 判定に合わせて踏み込む → ゆっくり戻る」形で、上方向の技は伸び上がり、下方向の技は沈み込むなど、技ごとに動きが変わります。専用モーションを登録したものは今までどおりそちらが優先されるため、用意できたものから少しずつ差し替えていけます。スタジオからモンスターごとに自動モーションのオン/オフと動きの強さを設定できます。

Version 0.97崖つかまりモーションが反映されない不具合を修正

スタジオから待機・歩行・崖つかまりなどの状態モーションを登録しても、画像だけがアップロードされ、ゲーム側の登録（data/fighters.json）には書き込まれていませんでした。このため崖つかまりのモーションを登録しても反映されない状態になっていました。スタジオを修正し、あわせて登録済みだったイルミネの崖つかまりモーションを有効にしています。

Version 0.96起動時の自動更新・ポーズからのバトル終了・タップの取りこぼし修正

起動したときに新しいバージョンがあれば、確認を出さずそのまま最新版で始まるようにしました。更新のお知らせは、遊んでいる最中に新しいバージョンが届いた場合だけ表示されます。ポーズ中に「つづける」「バトルを終了する」を選べるようにしました（終了は確認をはさみます）。また、ファイター選択で1P・CPUの玉やFIGHT!ボタンが1回のタップで反応しなかった問題を修正しました。横向きのままアプリを起動すると画面が上にずれることがあった問題も、表示領域が確定してから画面を組むように直しています。

Version 0.95育成がバトルに効くよう調整・バトルテストのUI改善

育てたステータスの手応えを強くしました。ちから／かしこさによる威力と吹っ飛ばしを引き上げ、カンストしたマスモンなら育成前の約半分の蓄積%で相手を撃墜できます。また、落下速度を回避ステータスから切り離してモンスターごとの固定値にしました。これまでは育てるほど落下が速くなって復帰が難しくなり、強くしたはずが自滅しやすいという逆転が起きていました。回避は横方向の移動速度と、技の後隙・着地隙の短縮に効くようになります。あわせてトレーニング画面の適性アルファベットがマスモン管理画面より暗く見えていた点を直し、管理者モードのバトルテストに ±100／±10 ボタンと「全999／全最低／既定」のまとめ変更を追加しました。

Version 0.94スタジオの不具合修正（動画の透明コマ・崖つかまりの確認・戻るボタン）

動画からコマを切り出すと透明なコマが混ざることがあった問題を修正しました。端末が絵を用意し終える前に取り込んでいたのが原因で、取り出せるまで待ち直すようにしています。あわせて、崖つかまりのように足元の高さが変わるモーションで、各コマの浮き具合と足元の軌跡をプレビューに表示するようにしました。モーション編集画面の「戻る」が端末の時計と重なって押しづらかった点も直しています。

Version 0.93技ごとの威力・攻撃判定をスタジオで設定可能に

モンスターの技ごとに、ダメージや吹っ飛ばし、判定の発生タイミング・持続コマ・判定の軌道を設定できるようになりました。「素早い/標準/大ぶり」を選んで威力スライダーを動かすだけで各数値は自動で決まり、判定の位置と大きさもコマ画像から自動で抜き出します。斧を後方から頭上を通して前方へ振り下ろすような、コマごとに動く判定も作れます。細かく詰めたい場合は詳細設定から個別に上書きできます。

登録済みのモーションが「登録済み」と表示されるようになり、差し替えたいものだけ選べば他はそのまま残ります。また、弓を撃つ・爆弾を投げるといった飛び道具の設定（速さ・大きさ・発射コマ・飛距離など）もスタジオから登録・調整できるようになりました。

Version 0.87モンスター作成スタジオを独立したアプリに

スタジオをゲームとは別のアプリとして開けるようにしました。共有ボタンから「ホーム画面に追加」すると専用アイコンで直接起動でき、ゲームを開く必要がありません。

Version 0.86モンスター作成スタジオを追加

管理者モードに「ツール」タブを追加しました。画像を選ぶだけで背景透過・コマ選択・表示位置の自動計算まで行い、そのままリポジトリへ登録できます。キャッシュ番号・バージョン・更新履歴も自動で更新されます。

Version 0.85全モーションに対応

待機・歩行・ダッシュ・ジャンプ・空中待機・しゃがみ・ガード・被弾・吹っ飛び・ダウン・崖つかまりの各状態に個別のモーションを設定できるようにしました。用意されていないモーションは自動的に別の状態（最終的には待機）へ切り替わるため、一部だけ用意した状態でも破綻しません。

Version 0.84キャラクター・技データを外部ファイル化

これまでプログラム内に直接書かれていたキャラクターと技の定義を、data/fighters.json と data/movesets.json に分離しました。モンスターやモーションの追加をツールから安全に行えるようにするための準備です。ゲームの内容に変更はありません。

Version 0.83操作パッドのカスタマイズとバトルの改善

設定画面に「操作パッド」タブを追加し、ボタンの大きさ・濃さ・左右反転に加えて、ドラッグでボタン位置を自由に配置できるようにしました。また、ジャストガード（ガードした直後に攻撃を受けると完全に無効化して反撃できる）としゃがみを追加し、空中では慣性が働くよう本家準拠の空中制御に変更しています。崖つかまりは崖の縁にぶら下がる表示になり、掴んでいる手・残り時間ゲージが見えるようになりました。そのほか、技の発動中に攻撃を受けると技が確実に中断されるように修正し、吹っ飛び後に減速するようにして低%でも大きく流されてしまう問題を解消。画面上部中央に出ていた不要な四角も撤去しました。管理者モードでは登録済みのBGM・SEを一覧から再生できます。

Version 0.82バトルを大幅に強化・軽量化

ヒットストップ、ベクトル変更（吹っ飛び中のスティック入力で軌道を変える）、受け身、急降下、着地隙、ワンパターン相殺、ダメージに比例したガード硬直と画面揺れを追加し、より本格的な対戦の手触りになりました。また、ステータス上昇の効果が途中で頭打ちにならないよう計算式を見直し、カンストまで育成が意味を持つようにしています。合わせて、CPUが復帰技を出せずに落下するバグ、乱闘で1回の攻撃が1人にしか当たらない問題、中断・再開やマルチでモーションが失われる問題を修正し、描画処理も軽量化しました。

Version 0.81トレーニングの上昇値を適性入りで表示

トレーニングの上昇値が、選択中のマスモンの適性を反映した実際の値で表示されるようになりました。例えばちから適性Aなら重り引きでちからが+20、適性Dなら猛勉強でかしこさが+10といった具合に伸び方が変わります。修行のコース選択でも、対象ステータスの適性を確認できるようにしました。

Version 0.80適性の表示を変更

適性ランクを、太い縁取りと立体的なグラデーションを付けたアルファベット表示に変更しました。A=赤／B=紫／C=緑／D=青緑／E=青とランクごとに色分けしています。

Version 0.79トレーニング画面を2カラムに変更

Version 0.78ステータス表示を刷新

マスモン管理画面で選択中のマスモンのステータスを表示するようにしました。アイコン・カラーバー・適性を並べた新しい表示で、トレーニング画面も同じ形式に統一。トレーニング内容もどの能力がどれだけ変化するかをアイコン付きで表示します。

Version 0.77バトルテストでステータスを自由に調整可能に
